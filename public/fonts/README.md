# Intro font

`oxanium-latin-600-normal.woff2` is the unchanged Latin, weight 600, normal-style
Oxanium font distributed by `@fontsource/oxanium` version `5.3.0`.

- Project: <https://github.com/sevmeyer/oxanium>
- License: SIL Open Font License 1.1; the full notice is in `OFL-Oxanium.txt`.
- Package: <https://registry.npmjs.org/@fontsource/oxanium/-/oxanium-5.3.0.tgz>
- Font SHA-256: `149d8c3d6fc6bbdbf3744cdcc585085b75ce21e444e6562ac257f8e43761e726`

The font is self-hosted and used only for the home intro subtitle. The intro
preloads this file and falls back to the project's existing display font.
